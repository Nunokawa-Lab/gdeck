Features

Everything you need, in the terminal

No GUI bloat. Save request definitions once, run them anytime — with env-based variable substitution built in.

⚡

CLI-first

Send HTTP requests directly from the command line with familiar curl-like ergonomics.

💾

Save & reuse

Store request definitions locally and run them by name — no copy-pasting URLs every time.

🖥️

Interactive TUI

Browse, run, edit, and delete saved requests in a full-screen terminal UI.

{ }

Env variables

Substitute {{VAR}} placeholders at runtime via env files — perfect for dev/staging/prod.

Quick start

Up and running in 30 seconds

Save a request, set env values, and run it — all from the terminal.

# Save a request with placeholders
$ gdeck save getUser GET https://api.example.com/users/{{USER_ID}} \
    -H 'Authorization: Bearer {{TOKEN}}'

# Set env values
$ gdeck env set USER_ID 42
$ gdeck env set TOKEN abc123

# Run the saved request
$ gdeck run getUser
Install

Pick your platform

Available on macOS, Linux, and Windows. Go is only required for go install.

Homebrew

macOS · pre-built binary · Go not required

brew install --cask Nunokawa-Lab/gdeck/gdeck

go install

macOS / Linux / Windows · requires Go 1.24+

go install github.com/Nunokawa-Lab/gdeck@latest

Binary download

All platforms · no dependencies

# macOS Apple Silicon
curl -LO https://github.com/Nunokawa-Lab/gdeck/releases/latest/download/gdeck-darwin-arm64
chmod +x gdeck-darwin-arm64
